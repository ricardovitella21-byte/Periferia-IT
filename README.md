# Periferia IT · Retos técnicos IA (Perxia 2.0)

Tres retos independientes. Cada carpeta es un proyecto completo (backend, chat web, herramientas, `demo.ts`, documentación) y se puede entregar por separado.

| Carpeta | Reto | Estado |
|---|---|---|
| [`reto-01/`](reto-01/) | Agente "Registro como Proveedor" | Completo (falta link público) |
| [`reto-02/`](reto-02/) | Agente "Registro de Contratos Vigentes" | Pendiente |
| [`reto-03/`](reto-03/) | Agente "Órdenes de Compra SAP" | Pendiente |

Cada reto trae su enunciado en `PRD.md` y sus datos de prueba en `fixtures/` (entregados por Periferia, no se modifican).

Requisitos: [Bun](https://bun.sh) 1.1+ y una API key de Anthropic para el chat (`demo.ts` funciona sin clave).
